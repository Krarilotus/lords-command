# Research prompt

Write a self-standing, open deep-research prompt: frame it around the problem and its neighbouring fields, not the design you lean towards, phrase it neutrally with all the context a stranger needs, and ask for named sources mapped to claims, how the field's leaders solve it, and whether it is industry standard or not yet done. When understanding it fundamentally needs several angles or related topics, split it into one prompt per angle. Propose each prompt in your reply as its own markdown code block, with the saved file's location in one line.
